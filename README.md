# Computational Work 1 – Analysis of Cleveland Heart Disease
Statistical analysis in Python (pandas, NumPy, Matplotlib, Seaborn, and SciPy) of the Cleveland Heart Disease dataset from the UCI Machine Learning repository. The work uses the variables age, sex, maximum heart rate (thalach), and presence of heart disease (target).

# Steps:

Preprocessing: handling missing values, duplicates, and binarizing the target.
Age frequency distribution.
Data visualization (histogram and other charts).
Discrete random variable, with age ranges of patients with disease.
Chi-square test between sex and presence of disease.
Pearson correlation between age and maximum heart rate.

## How to Run 

#### 1. Download the dataset 
1. On the main page of this repository, click on the file `processed.cleveland.data`.
2. 2. In the top right corner, click the download icon (downward arrow) to save the file to your computer.

#### 2. Open the notebook in Google Colab 
1. Go to [colab.research.google.com](https://colab.research.google.com).
2. Click **File → Open notebook** and choose the **GitHub** tab.
3. Paste the address of this repository and select the notebook `Trabalho_Computacional_1.ipynb`.
> Alternative: download the notebook from this repository and upload it to Colab via **File → Upload notebook**.

#### 3. Load the dataset 
1. Run the first cell of the notebook.
2. Click **Choose files** and select the `processed.cleveland.data` file you downloaded.
3. Wait for the upload completed message.

#### 4. Run the rest of the code 
Run the remaining cells in order, or use **Runtime → Run all**.
